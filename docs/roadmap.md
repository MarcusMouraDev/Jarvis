# Roadmap — Jarvis Evolution

## M1 — Safe Agent Core

1. Baseline limpa e documentação permanente.
2. Catálogo de agentes e política de workspace.
3. Event store SQLite e importação legada.
4. Segurança de sessão em loopback.
5. Tool Gateway e aprovações exatas.
6. Gateway de modelos, privacidade e orquestrador.
7. API segura, SSE reproduzível e interface operacional.
8. Cobertura end-to-end, rastreamento e entrega.

O M1 termina após validação de lint, tipos, testes unitários, build e Playwright, com falhas ambientais classificadas e sem regressão intencional do V23.
